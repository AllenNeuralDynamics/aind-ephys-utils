Conventions
===========

This package relies on stable naming conventions for dimensions, coordinates,
and attributes.

Dimensions
----------

- trial
- unit
- time

Coordinates
-----------

- event (events dimension)
- t (event time variable in events DataArrays)

Attributes
----------

- ephys.kind
- ephys.timebase
- ephys.time_unit
- ephys.valid_intervals

These conventions are defined in ``aind_ephys_utils.core.conventions``.
